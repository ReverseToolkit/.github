## ReverseToolkit

Android and binary reverse-engineering tools.

- APK / HAP decompiler: [ASC](https://github.com/BritneyOvO/ASC_rs)
- Flutter unpacking: [blutter-rs](https://github.com/BritneyOvO/blutter-rs)
- Xposed: [SpecPosed](https://github.com/BritneyOvO/SpecPosed)
- ART hook: [SpecPlant](https://github.com/BritneyOvO/SpecPlant)
- Injection: [SpecZygisk](https://github.com/BritneyOvO/SpecZygisk), [SpecInjector](https://github.com/BritneyOvO/SpecInjector)
- ARM64 trace: [GumTrace](https://github.com/BritneyOvO/GumTrace), [QTrace](https://github.com/BritneyOvO/QTrace), [trace-ui](https://github.com/BritneyOvO/trace-ui)
