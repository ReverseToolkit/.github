## ReverseToolkit

Android 与二进制逆向工具。

- [ASC_rs](https://github.com/ReverseToolkit/ASC_rs) — Android / HarmonyOS 按需反编译
- [blutter-rs](https://github.com/ReverseToolkit/blutter-rs) — 从 APK 识别并拆包 Flutter，带按版本的 Dart VM 桥
- [CommPosed](https://github.com/ReverseToolkit/CommPosed) — Zygisk 框架，运行 Xposed 模块
- [CommZygisk](https://github.com/ReverseToolkit/CommZygisk) — 面向 KernelSU、APatch、Magisk 的 Zygisk 模块
- [CommInjector](https://github.com/ReverseToolkit/CommInjector) — 向 Android 进程注入 so 和 dex
- [CommAnalyser](https://github.com/ReverseToolkit/CommAnalyser) — ARM64 Android 动态插桩
- [CommPlant](https://github.com/ReverseToolkit/CommPlant) — ART hook 库
- [kuna](https://github.com/ReverseToolkit/kuna) — 面向 agent 的反编译器
